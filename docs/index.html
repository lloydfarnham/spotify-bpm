Spotify BPM Checker

A small personal tool that finds the tempo (BPM) of the songs in my Spotify Liked Songs.

It reads my Liked Songs from Spotify (read-only), then looks up each track's tempo from public music-data services, so I can sort and explore my library by BPM.

Data sources

  • BPM data provided by GetSongBPM.
  • Audio features from ReccoBeats.
  • Track library via the Spotify Web API.
Tempo data: GetSongBPM
